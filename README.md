# Petshop do Bê - Fase 1

Site desenvolvido para a disciplina de Fundamentos de Sistemas Web (PUCRS), referente à Fase 1 do projeto: plataforma online de comércio de produtos e serviços de um petshop.

## Funcionalidades

- **index.html**: página inicial com apresentação do petshop.
- **produtos.html**: exibe 2 produtos de cada categoria (rações não perecíveis, acessórios/brinquedos, produtos de higiene e limpeza, e uma categoria extra de saúde e cuidados), cada um com foto, descrição e valor. As fotos ficam na pasta `images/`.
- **servicos.html**: exibe os serviços oferecidos (banho e tosa, com e sem tele-busca), cada um com descrição e valor.
- **contato.html**: informações de contato e horário de funcionamento.

Todas as páginas compartilham o mesmo cabeçalho (header, com nome do petshop e menu de navegação) e rodapé (footer, com informações legais, contato e links de navegação).

## Tecnologias

- HTML5 puro, sem uso de CSS ou Bootstrap (conforme requisito da Fase 1).
- Sem uso de JavaScript (será implementado na Fase 2).
